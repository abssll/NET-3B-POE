# Week 8: Secure Network Design

## Learning Outcomes

Students must demonstrate technical execution, evidence collection, analysis and reporting skills.

## Objective

The objective of this practical was to design a secure network by analysing network interfaces, routing information, and active network configurations. Secure network design uses segmentation, VLANs, and access controls to reduce security risks and improve network management.

## Reflection

This practical focused on analysing network configuration information used to support secure network design. Network interfaces, routing tables, and active network device configurations were reviewed to better understand how systems communicate within a network environment.


## Conclusion

The objectives of this practical were successfully achieved. Network interface information, routing data, and device configuration details were collected and analysed to support secure network design principles.

The practical demonstrated the importance of proper network configuration, addressing, and routing within secure environments. These concepts form the basis for implementing VLANs, network segmentation, and access control mechanisms in larger network infrastructures.
Secure network design principles such as segmentation, access control, and controlled communication paths help reduce security risks and improve visibility for SOC analysts. Understanding network architecture is essential for protecting systems against unauthorized access and network-based threats.
